Sign in with your GitHub key

This page saves your stocks and rules straight into your private repository. It needs a GitHub access key that can only reach your alert repositories. You do this once per device.

1

Create a key (skip if you already have one)

Create a key on GitHub ↗
  1. Name, expiry and permissions are filled in for you.
  2. Under Repository access pick Only select repositories → and your dashboard repository.
  3. Click Generate token and copy it (it starts with github_pat_).
2

Paste it here

The key stays in this browser and is only sent to GitHub. Sign out to remove it.
